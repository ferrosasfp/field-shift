Field Shift: cómo funciona por dentro

Guía para presentar la demo en el workshop. Recorre la página en el orden de los 5 clics de la demo y, en cada paso, señala qué parte del código se ejecuta. Los números de ejemplo son los de Carumas con datos de NASA POWER 2001-2025.

La página

La demo en 5 clics

La pregunta que responde: con 25 años de datos de satélite, ¿qué rotación conviene en mi zona y cuándo habría pagado un seguro?

  1. Elegir Carumas y presionar «Consultar NASA»

    El navegador pide GET /api/field-shift/nasa?zona=carumas. El servidor consulta NASA POWER (lluvia, temperatura, mínima y humedad del suelo, mensual 2001-2025). Si NASA no responde en 8 s, usa la copia guardada en el repo. El estado dice si los datos vienen «en vivo» o de la «copia guardada».

    hooks/useClima.ts → app/api/field-shift/nasa/route.ts → services/nasa.ts

  2. Leer las 6 tarjetas

    Carumas: 110 mm de lluvia en la campaña (oct–abr), 21 % de campañas secas, 80 % de meses con helada, mínima típica −3.4 °C, y los años El Niño llueven 9 % menos. Las tarjetas en ocre son alertas.

    services/rotacion.ts → analizarClima() · components/TarjetasClima.tsx

  3. Cambiar a «Solo años El Niño»

    Se recalcula todo usando solo las 8 campañas El Niño (lista RONI de NOAA). La sequía sube a 25 % y la recomendación cambia: haba → quinua pasa a papa → haba. Buen momento para hablar de 2026-27, que viene con El Niño.

    services/enso.ts → fase() · analizarClima(meses, 'nino')

  4. Mover las prioridades

    Cuatro sliders de 0 a 3: comida, ingreso, cuidar el suelo y resistir sequía y heladas. Se prueban las 36 combinaciones año 1 → año 2 con 6 cultivos y se muestran las 3 mejores, con sus razones en lenguaje simple. No hay llamada al servidor: todo corre en el navegador.

    recomendarRotaciones() · services/razones.ts · components/Rotaciones.tsx

  5. Mover el umbral del seguro

    El índice es la humedad del suelo promedio de diciembre a febrero. Si cae bajo el umbral, la póliza paga. Con el umbral sugerido (0.341) habría pagado en 6 de 24 campañas, 3 de ellas El Niño (marcadas con «N»).

    backtest() · umbralSugerido() · components/BacktestSeguro.tsx

Extra opcional: si conectas Core o MetaMask en Fuji aparece el bloque de la póliza para comprarla y reclamar el pago en Avalanche. Es un contrato educativo, no auditado, solo para testnet.

El cerebro

Cómo decide la rotación

Las reglas son simples a propósito: cualquiera puede leerlas y explicar por qué la app recomienda algo. Primero se mide qué tan bien le va a cada cultivo con el clima de la zona:

// services/rotacion.ts
function aptitud(cultivo, clima) {
  const agua   = Math.min(1, clima.lluvia / cultivo.aguaMinima)
  const sequia = clima.frecuenciaSequia * ((5 - cultivo.toleranciaSequia) / 4)
  const helada = clima.riesgoHelada    * ((5 - cultivo.toleranciaHelada) / 4)
  return { agua, puntaje: agua * (1 - sequia) * (1 - helada) }
}

Ejemplo: haba → quinua en Carumas

Haba (necesita 350 mm)110/350 = 0.320.21 × 3/4 = 0.160.80 × 2/4 = 0.400.16
Quinua (necesita 300 mm)110/300 = 0.370.21 × 0/4 = 00.80 × 1/4 = 0.200.29

Con eso se arman cuatro componentes por rotación, cada uno entre 0 y 1, y se promedian con los pesos de los sliders:

Las 3 primeras rotaciones de Carumas empatan casi en 55: haba y quinua compensan la poca lluvia con suelo y tolerancia al frío. El MVP original da el mismo empate.

Otras reglas del motor
  • Campaña: octubre a abril. Oct–dic cuentan para la campaña que empieza ese año; ene–abr, para la del año anterior. Solo entran campañas con los 7 meses completos.
  • Campaña seca: lluvia menor al 75 % del promedio de todas las campañas.
  • Helada: un mes con temperatura mínima (T2M_MIN) bajo 0 °C.
  • Umbral sugerido: percentil 20 del índice, para que la póliza pague más o menos 1 de cada 5 campañas.
  • El backtest usa siempre todas las campañas, aunque cambies el escenario.

Confianza

Da lo mismo que el MVP original

El código se portó línea por línea desde el MVP en JavaScript. Para probarlo, un script ejecuta el código original sobre los mismos datos y guarda la salida en golden.json. Los tests comparan el código nuevo contra ese archivo: números con 9 decimales y las razones palabra por palabra, en 4 zonas × 3 escenarios × 6 combinaciones de prioridades.

npm run test                                   # 243 tests, incluido el golden
npm run field-shift:golden -- <ruta-al-mvp>    # regenerar el golden
npm run test:e2e -- field-shift                 # los 5 clics en un navegador real

Capa opcional

La póliza paramétrica en Avalanche

El contrato PolizaParametrica.sol paga sin ajustador: un oráculo publica el índice de la temporada y, si queda bajo el umbral, cada asegurado reclama su pago. Quien adopta una rotación resiliente paga 20 % menos de prima.

FunciónQuiénQué hace
comprarPoliza(zona, rotacion)ProductorPaga la prima (0.01 AVAX o 0.008 con rotación)
reportarIndice(zona, indice, hash)OráculoPublica la humedad × 1000; una sola vez por zona
reclamar(zona)AseguradoCobra 0.05 AVAX si el índice quedó bajo 450

Desplegado en Fuji: 0x594c…961c, con la zona Carumas y 0.2 AVAX de fondos.

# Disparar el pago al final de la demo (índice 380 = humedad 0.380, bajo el umbral)
CONTRATO=0x594c5D7Bb4ff20F296c1CfacFE4c5555e278961c INDICE=380 npm run contracts:reportar:fuji

Después de reportar ya no se venden pólizas en esa zona. Hazlo al final. El contrato es educativo y no está auditado: solo Fuji y wallets de prueba.

Para los equipos

Limitaciones e ideas para el hackathon

  • Celdas de ~50 km: Ichuña y Yunga dan lo mismo porque caen en la misma celda. Comparar con estaciones de Senamhi.
  • La lluvia de NASA sale baja (110 mm en Carumas frente a ~300 mm de Senamhi). Calibrar o usar otra fuente.
  • Valores de cultivos aproximados: validarlos con un agrónomo o una agencia agraria.
  • Agregar NDVI de MODIS o humedad de SMAP, un mapa para marcar la parcela, los valles con riego, o un oráculo con Chainlink Functions.
  • Elegir el escenario automáticamente con el pronóstico de ENFEN antes de sembrar.
Datos: NASA POWER (mensual, 2001-2025). Proyecto de ejemplo para el workshop; no es un producto oficial de NASA. Código en la rama feat/001-field-shift de NexusFactory.
